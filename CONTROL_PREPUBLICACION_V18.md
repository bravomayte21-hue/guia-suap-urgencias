# CONTROL FINAL DE PREPUBLICACIÓN · MAESTRA V18

Fecha: 22/09/2026

## Resultado técnico
- 75 fichas clínicas conservadas.
- IDs clínicos únicos y recursos de imagen presentes.
- Procedimientos T01–T18 operativos.
- Módulos Antibióticos, Comparativas, Calculadoras y equivalencias antihipertensivas incluidos en precaché offline.
- JavaScript y paquete ZIP sometidos a validación antes de entrega.

## Seguridad clínica ya auditada
- RCP/ALS adulto contrastado con ERC/RCUK 2025.
- Capas de seguridad para anafilaxia, asma/EPOC, pediatría respiratoria, hiperpotasemia, obstetricia y RSI/sedoanalgesia.
- Farmacología base de ketamina, rocuronio, midazolam y fentanilo contrastada con CIMA; no se fijan mL finales sin confirmar la presentación real.
- Antibióticos: jerarquía PRAN/GTA-SNS -> CIMA -> PIRASOA/local. No se completa por inferencia lo que requiere pauta local.

## BLOQUEOS PARA PUBLICACIÓN CLÍNICA DEFINITIVA
1. **Stock real SUAP**: fotos/listado de ampollas, concentraciones y dispositivos. Necesario para cerrar mg/µg -> mL, diluciones, velocidades y detalles de IO.
2. **Antimicrobianos locales**: documentar pautas que dependan de protocolo/resistencia de Cádiz/área sanitaria.

## Decisión de versión
V18 es **candidata técnica de prepublicación**, apta para revisión interna. No se etiqueta como versión clínica pública definitiva mientras existan los dos bloqueos anteriores.

## Regla de discrepancias
Si una infografía antigua difiere de una capa de seguridad actualizada, prevalece la capa de seguridad. La infografía se conserva por trazabilidad hasta su sustitución gráfica definitiva.
